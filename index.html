⚙ Paramètres
Liaison des UID ↔ pseudos
Utile si un UID a été ajouté ailleurs que via une connexion à l'appli (tableau DPS, import manuel...) — associe-le à un pseudo ici, repris ensuite partout (historique, collections).
Sauvegarde complète de l'appli
Exporte TOUT (collections, liaisons UID, tableau DPS, historique) en un seul fichier — à réinjecter dans une autre version du fichier via "Importer les données" pour ne rien perdre en changeant de version.
Réimporter un fichier ne crée jamais de doublons : les persos et lignes déjà présents sont reconnus, seul ce qui est nouveau ou plus récent est ajouté.
Connexion à Enka (vitrine)
L'appli interroge Enka directement ; si Enka limite les requêtes ou ne répond pas, elle attend, réessaie, puis passe par des relais publics et retient le chemin qui marche. Le test ci-dessous montre ce qui fonctionne depuis ce navigateur.
Proxy personnel (optionnel, le plus fiable)
🛠 Créer mon proxy gratuit (Cloudflare Workers) — à faire une seule fois
  1. Crée un compte gratuit sur dash.cloudflare.com, puis ouvre Workers & Pages ▸ Create ▸ Create Worker et valide « Deploy ».
  2. Clique Edit code, remplace tout le contenu par le code ci-dessous, puis Deploy.
  3. Copie l'adresse du Worker (se termine par .workers.dev), colle-la dans le champ ci-dessus, enregistre, puis lance « Tester la connexion ».

      
Ce proxy relaie simplement la requête vers Enka avec son propre User-Agent (demandé par la doc d'Enka) et sa propre adresse IP : c'est ce que font les sites qui affichent les vitrines. Offre gratuite : 100 000 requêtes par jour.

➜ Fais défiler le tableau vers la droite pour voir Moyenne, PBR et PB Hit (ou masque R1–R7)

    

      

    

    

    

      Clique sur un en-tête de colonne pour trier (1er clic : croissant, 2e clic : décroissant) ; clic droit sur l'en-tête (appui long sur téléphone) pour filtrer. R1 à R7 sont tes 7 mesures, Moyenne leur moyenne, PBR ton meilleur résultat et PB Hit ton meilleur coup unique. Le dégradé de MOYENNE est calculé sur toutes les lignes, indépendamment du tri. Pour un personnage connu, l'élément et sa couleur sont automatiques ; pour un nom inconnu, un choix d'élément reste disponible.
